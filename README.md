# 🤗 Best Friend AI

**Your Bengali Best Friend - Who Listens, Keeps Secrets & Helps You Feel Better.**

No API Key Needed. 100% Free. Works on Mobile.

### 🔴 LIVE DEMO: https://best-friend-ai.onrender.com

---

## ✨ Features

- **💬 Real AI Chat:** Powered by ChatGPT (GPT-4o-mini) via Puter.js - no API Key required
- **🤫 Secret Safe:** Your personal thoughts, problems, and secrets - all are safe here
- **📊 Mood Tracker:** Save your daily mood with emojis and see your 7-day mood graph
- **🇧🇩 Bengali + English:** The AI replies in the same way you talk to it
- **📱 Mobile Friendly:** Works like an app on your phone

## 🚀 How To Use

1. Go to the live link: **https://best-friend-ai.onrender.com**
2. Enter your **Name**
3. Enter a Password - Example: `Sam@1234`
   - Must contain 1 lowercase letter, 1 uppercase letter, 1 number, and 1 symbol (@#&*$)
4. Login and talk freely!

## 🛠️ Tech Used

- HTML / CSS / JavaScript
- Chart.js - For the Mood Graph
- Puter.js - Free AI (GPT-4o-mini)
- Deployed on Render - Static Site
